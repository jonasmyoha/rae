# Legacy examples

These programs are retained for source archaeology and historical links. They
are not supported examples, do not appear in the default Devtools catalogue,
and are not compiled by the example smoke suite.

`raylib/` contains examples tied to Rae's former Raylib rendering path. New
visual examples use GPU2D or Rae's deferred 3D renderer, with SDL3 providing
the platform, window, and input boundary.
