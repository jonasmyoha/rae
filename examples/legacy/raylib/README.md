# Archived Raylib examples

These examples document Rae's former Raylib integration. They are intentionally
frozen and excluded from normal builds. Do not copy their rendering or UI
architecture into new code.

Current equivalents use:

- `lib/gpu2d.rae` for 2D rendering;
- `lib/renderer_deferred.rae` for 3D rendering;
- `.raescene` plus `lib/ui` for interface layout;
- `lib/sdl3.rae` for platform input or software-framebuffer presentation.
