## Visual tests are allowed again (2026-09-12, #924)

The standing "NO VISUAL TESTS" clause that the #904-#923 tasks carried (do not
run `run_examples.sh`, `make test-examples`, a screenshot gate or an example in
a window; hand the visual check to the user) is LIFTED. From #924 on, a queue
task may run the visual example gates and examples itself to verify its own
claims — with explicit timeouts, one run at a time, and still never alongside a
live `watch-tests.sh` run. Every still-open task that carried the clause has it
replaced by a "VISUAL TESTS OK" note; the clause stays verbatim on the closed
tasks as the record of how they were verified.

`QUESTION:` in the line body. Never put a started task back to `[ ]`.

File a new task as `- [ ] the task text`; SUMU mints the `#id`, so never
guess one. Line order is the queue order.
