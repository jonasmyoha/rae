Scope: lower `opt T` for non-reference `T` to a per-type monomorphized `struct rae_opt_T { bool has; T value; }` (the mechanism `List(T)` already uses); `opt T` needs a drop only if `T` does (type_needs_cascade_drop); reserve `RaeAny` for `Any` only.
