Motivation: #653 verified `if let x: view/mod <Int|Float|Bool> => list.viewAt/modAt(index:)` lowers correctly (the `emit_list_if_let` peephole emits `rae_View_Int64 x = { .ptr = &__rae_list->data[i] }`).
