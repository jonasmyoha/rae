The Live Language for Creative Systems.

Rae combines the safety of modern reference models with the raw performance of C, built from the ground up for hot-reloading and systems that never stop.

⚡

Instant Hot-Reload

Patch logic, tweak UI values, and swap functions in a running process. The Rae VM preserves your application state so you can iterate at the speed of thought.

🛡️

Zero-Cost Safety

Explicit view and mod references. No garbage collection, no hidden pointers. Compile-time lifetime checks ensure your aliases never escape their scope.

⚙️

Explicit Semantics

No implicit moves or magic sharing. = always copies. => always binds. Predictable performance for systems where every microsecond counts.

🏗️

Native C Backend

Rae compiles to clean, readable C11. Use existing C libraries effortlessly and deploy to any platform that has a C compiler.

Memory Control

Fine-grained control over aliasing and copying without the boilerplate.

Reactive Logic

Perfect for ECS-based games and interactive simulations.
