# T001 - Format CLI options work under tests

## Summary
- taught the `rae format` command to parse `--write`/`--output` flags before loading source files, so option order matches user expectations
- expanded `compiler/tools/run_tests.sh` to accept multi-word commands, support a `{{TMP_OUTPUT}}` placeholder, and capture formatter output written to files
- added regression test `203_format_output_option` to ensure `format --output` produces the canonical program text

## Testing
- `cd rae/compiler && make test`
- `TMP=$(mktemp /tmp/rae_write_XXXX.rae) && cp rae/compiler/tests/cases/200_format_type.rae "$TMP" && rae/compiler/bin/rae format --write "$TMP" && diff -u rae/compiler/tests/cases/200_format_type.expect "$TMP" >/dev/null && rm "$TMP"`
- `TMP=$(mktemp /tmp/rae_out_XXXX.txt) && rae/compiler/bin/rae format --output "$TMP" rae/compiler/tests/cases/200_format_type.rae && diff -u rae/compiler/tests/cases/200_format_type.expect "$TMP" >/dev/null && rm "$TMP"`
