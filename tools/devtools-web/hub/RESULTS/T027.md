# T027 - Implement Cooked String Interpolation

## Result
Completed.

## Changes
- **Lexer**: Added `TOK_STRING_START`, `TOK_STRING_MID`, `TOK_STRING_END`. Updated `scan_string` to handle `{` and `}` transitions and track `interpolation_depth`. Added validation for escapes including `\{`, `\}`, `\u{...}`.
- **Parser**: Added `unescape_string` helper to process escapes and strip quotes. Updated `parse_primary` to desugar interpolation into a chain of `rae_str_concat` and `rae_str` calls.
- **Runtime**: Added `rae_str_concat`, `rae_str_i64`, and `rae_str_cstr` to `rae_runtime`. Used C11 `_Generic` to provide a unified `rae_str` macro for the C backend.
- **VM**: Registered `rae_str` and `rae_str_concat` as native functions. Updated `vm_compiler` to handle these intrinsics and use `value_string_copy` for pre-processed string literals.
- **Pretty Printer**: Updated to handle new string tokens and add escaping back to string literals.
- **Tests**: Added `316_interpolation` (basic usage, math, escapes) and `022_error_empty_interp` (empty `{}` check).

## Notes
- Interpolation is fully supported in both Live (VM) and Compiled (C) modes.
- Memory for concatenated strings in C backend currently leaks (no GC yet).
