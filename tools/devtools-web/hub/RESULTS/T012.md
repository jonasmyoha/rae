# T012 - Hot-reload + dev runtime support

## Summary
- Added `VmRegistry` so compiled chunks can be cached/replaced and exposed it through the CLI via `bin/rae run --watch <file>`
- Refactored `bin/rae run` to share a compilation path, introduced the `--watch` flag, and added filesystem polling that recompiles/reruns whenever the file changes
- Documented the embedding story in `docs/vm-plan.md` and updated the READMEs so developers know about the watch mode

## Testing
- `cd rae/compiler && make test`
- `cd rae/compiler && ../bin/rae run --watch ../examples/hello.rae` *(manual hot-reload demo)*
