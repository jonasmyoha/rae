# T026 - Implement Char Literals

## Result
Completed.

## Changes
- **Lexer**: Added `TOK_CHAR`, implemented `scan_char_literal` with escape sequence support (`\n`, `\'`,`\\`, `\u{HEX}`).
- **AST**: Added `AST_EXPR_CHAR`, `Str char_lit` (raw text), `int64_t char_value` (codepoint).
- **Parser**: Updated `parse_primary` to handle `TOK_CHAR`, parsing content to codepoint.
- **VM**: Added `VAL_CHAR` type, updated `value_print` to print UTF-8 encoded char. Updated `vm_compiler` to compile char literals.
- **C Backend**: Updated to emit `int64_t` for char literals.
- **Pretty Printer**: Formats char literals with single quotes.
- **Tests**: Added `315_char_literals` covering basic and escape cases.

## Notes
- `Char` is treated as a distinct type in VM (`VAL_CHAR`).
- C backend emits `int64_t` values.
- Fixed a regression in C backend where `log(string_var)` was incorrectly emitting integer log call.
- Fixed a formatting regression where normal strings were double-quoted.
