# T014 - Devtools example runner

## Summary
- Added an “Examples” panel to the dashboard: it enumerates `../rae/examples`, shows each project’s files, and lets you run them through the new `bin/rae run` interpreter without leaving the UI
- Implemented server support (`/api/examples`, `/api/examples/source`, `/api/examples/run`) plus an ExampleRunner that streams VM output over WebSocket events
- Updated configuration (optional `examplesPath`) and documentation so teams know how to point the panel at their own Rae demos

## Testing
- `bun run lint`
- `cd rae/compiler && make test`
