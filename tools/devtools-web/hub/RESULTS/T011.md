# T011 - Implement minimal Rae bytecode VM

## Summary
- Added the initial bytecode runtime: new chunk/value structures, a VM loop, and a compiler that lowers `func main` bodies with `log` calls into bytecode
- Extended `bin/rae` with a `run` command and documented it in both READMEs; shipped `examples/hello.rae` plus a regression test (`300_vm_hello`) that exercises the interpreter
- Bytecode supports constants + builtin `log`/`logS`, with the pipeline ready for future opcodes and hot-reload work (T012)

## Testing
- `cd rae/compiler && make test`
- `rae/compiler/bin/rae run examples/hello.rae`
