# T029 - Implement Formatter Disable Pragmas

## Result
Completed.

## Changes
- **Pretty Printer**: Updated `pretty.c` to support `# raefmt: off` and `# raefmt: on` pragmas.
  - Pre-scans comments to find line ranges for verbatim regions.
  - Passes the original source buffer to `pretty_print_module`.
  - When a declaration or import falls within an "off" range, the formatter skips normal processing and prints the original source text byte-for-byte.
- **CLI**: Updated `main.c` to pass the source buffer to the formatter.
- **Tests**: Added `206_format_disable` to verify that code inside disable blocks is preserved with its original spacing and indentation.

## Notes
- Nested blocks are handled by a simple first-off/first-on toggle.
- Verbatim regions respect original line endings and indentation.
