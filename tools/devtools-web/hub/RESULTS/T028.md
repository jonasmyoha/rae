# T028 - Implement Trailing Comma Policy

## Result
Completed.

## Changes
- **Pretty Printer**: Implemented Dart-like trailing comma policy in `pretty.c`.
  - Multiline lists (args, params, return items, object fields) now MUST have a trailing comma.
  - Single-line versions of the same constructs MUST NOT have a trailing comma.
  - Decision between multiline and single-line is now based on a deterministic heuristic (item count > 3 or estimated line length > 100/120).
- **Consistency**: Applied the same policy to:
  - Function parameters
  - Function call arguments
  - Return item lists
  - Object literals
- **Tests**: Added `205_format_commas` to verify both multiline and single-line cases.

## Notes
- Developer "style" regarding trailing commas is now ignored; the formatter always produces canonical output based on layout decisions.
