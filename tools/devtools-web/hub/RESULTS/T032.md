# T032 - Implement Standard Library Bootstrap & Random API

## Result
Completed.

## Changes
- **Standard Library**:
  - Created `rae/lib/core.rae` for auto-imported core functions (`nextTick`, `sleepMs`).
  - Created `rae/lib/math.rae` for math and random functions.
- **Auto-Import Logic**:
  - `main.c` now automatically loads `lib/core.rae` for every module unless `import nostdlib` is present.
- **Deterministic PRNG**:
  - Implemented a stable 64-bit LCG in both `rae_runtime.c` (Compiled) and `main.c` (Live natives).
  - Ensured identical constants and logic to provide cross-backend determinism given the same seed.
- **Random API**:
  - `seed(n: Int)`: Sets the global random state.
  - `random(): Float`: Returns a value between 0.0 and 1.0.
  - `randomInt(min: Int, max: Int): Int`: Returns an inclusive random integer.
- **Tests**:
  - `317_stdlib_random`: Verifies deterministic sequences in VM.
  - `318_nostdlib`: Verifies that `import nostdlib` successfully prevents auto-imports.
  - `319_auto_stdlib`: Verifies that `core.rae` is available by default.
  - Updated existing build tests to use `import nostdlib` to remain minimal.
