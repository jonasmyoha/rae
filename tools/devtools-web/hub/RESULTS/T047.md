# Task T047 - Update `AGENTS.md` and Rae Language Specification for Naming Conventions

## Summary
Added formal naming convention rules for functions (camelCase) and types (PascalCase) to both `AGENTS.md` and the Rae Language Specification (`rae/spec/rae.md`).

## Changes
- **`AGENTS.md`**: Added a new section "Global Language Rules (MUST BE ENFORCED)" with the naming convention rules.
- **`rae/spec/rae.md`**:
    - Updated Section 1.2 "Identifiers" to include the naming conventions.
    - Updated Section 3.1 "Type Definition" to state that type names MUST follow `PascalCase`.
    - Updated Section 4.1 "Function Definition" to state that function names MUST follow `camelCase`.

## Acceptance
- The naming convention rules are clearly documented in `AGENTS.md` and `rae/spec/rae.md`.
