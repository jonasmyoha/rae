# Task T048 - Lexer & Parser: Generic Type Syntax `List[T]`

## Summary
Implemented support for parsing and formatting generic type syntax in Rae, allowing types like `List[Int]` or `Map[K, V]`.

## Changes
- **`ast.h`**: Modified `AstTypeRef` to include a `generics` field, which is a linked list of `AstTypeRef` to represent generic type parameters.
- **`parser.c`**:
    - Modified `parse_type_ref` to recognize and parse `Ident '[' Type (',' Type)* ']'` syntax.
    - Added `append_type_ref` helper function to manage the linked list of generic type arguments.
- **`pretty.c`**: Modified `pp_write_type` to correctly format generic type references, printing the base type followed by generic parameters enclosed in square brackets and separated by commas.

## Acceptance
- `def x: List[Int]` parses and formats correctly, including the generic parameter, as verified by `rae format`.
