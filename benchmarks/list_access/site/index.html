Safe indexing, measured.

Rae uses optional, logical-length-checked List indexed access. Collection loops lower to direct iteration without optional construction or per-element bounds checks.

Final recommendations
  1. Keep all public List indexed access optional and bounds-checked; these measurements do not justify an unsafe accessor.
  2. Use loop let item: view Item in items for sequential hot paths and viewAt + if let for random access to large structs.
  3. Optimize Rae's general owned opt T representation separately; do not make List indexing unsafe to avoid RaeAny.
  4. In hot loops that write by index, read with if let … = copyAt and write with if let slot: mod T => modAt. copyAtDefault and set are safe too but several times slower today, until the compiler lowers them the same way (see the scatter card).

Writing by index: the accessor matters

The read-only cards above all use the two Rae shapes the C backend lowers to a bare length check and load: the collection loop and an immediate if let … = copyAt(index:). The scatter card is the first to also write by index, the way a physics solver, particles or skinning do. Written with the narrowed forms, if let to read and if let slot: mod Float => modAt(index:) to write, Rae runs at 1.20× checked C. Writing with set(index:value:) instead costs 3.38×, and reading with copyAtDefault(index:) as well costs 3.90×: those two accessors are still ordinary function calls that build an optional (copyAtDefault goes through copyAt) or carry a warning path (set). Every spelling is bounds-checked; the difference is only how much of that the compiler can see through. This is why a first contact-solver test (docs/physics-box3d-port-research.md) looked 6× slower than C while this page showed parity: it used the two slow accessors.

What RaeAny means here

opt view T and opt mod T are nullable references: one null check, no allocation, and no element copy. A general owned opt T has to carry either none or an owned value of arbitrary size, so the current C ABI uses a 48-byte RaeAny tag/union/drop record. Values wider than its inline union, including the benchmark's 64-byte Particle, are heap-allocated; heap-owning structs are also deep-copied and later dropped.

This page does not measure that general RaeAny path. Its owned-value spelling is if let particle: Particle = particles.at(...). The C backend recognizes this immediate narrowing and emits one logical-length check followed by a direct local copy, without constructing RaeAny. A stored, passed, or returned owned opt Particle may use RaeAny and therefore deserves separate correctness and performance work before it can be benchmarked honestly. Do not infer RaeAny overhead from the Particle numbers below.

Methodology

All implementations use equivalent deterministic data, access counts, and validated checksums. Timings exclude allocation/setup, use each runtime's monotonic high-resolution clock, and include nine in-process repetitions; the first two are discarded. C and Rust include explicitly unchecked controls. Rae exposes no unchecked List API.

The strided, random and invalid-index cases wrap with % length, and that divisor goes through an opacity barrier in Rae, C and Rust (opaqueIndex, a volatile read, black_box), so each performs a real division. Until 2026-10-01 the divisor was the constant 65,536: C and Rust always turned % 65536 into a bit mask, Rae only when the C compiler inlined far enough, so those cards measured constant folding and Rae's numbers swung 2.5× with unrelated code changes.

Rae/C/Rust use contiguous 64-byte inline Particle structs. JavaScript uses ordinary heap objects and Python uses tuples; those struct results answer “what does idiomatic access cost in this runtime?” rather than “how does identical memory layout compile?”

# Scatter update: a contact-solver-shaped kernel (docs/physics-box3d-port-research.md).
# Each contact reads two bodies' velocities through indices it holds, computes
# an impulse, clamps it, and WRITES both bodies back — the read-modify-write by
# index that physics, particles and skinning do, and that the read-only
# scenarios above never exercise. Three spellings of the same safe access.
const scatterBodyCount: Int = 4096

const scatterContactCount: Int = 16384

const scatterIterations: Int = 50

type ScatterWorld {
  vx: List(Float)
  vy: List(Float)
  vz: List(Float)
  invMass: List(Float)
  bodyA: List(Int)
  bodyB: List(Int)
  nx: List(Float)
  ny: List(Float)
  nz: List(Float)
  accumulated: List(Float)
}

func filledFloats(count: view Int, value: view Float) ret List(Float) {
  var values: List(Float) = createList(Float, cap: count)
  var index: Int = 0
  loop index < count {
    values.add(value: value)
    index = index + 1
  }
  ret values
}

func makeScatterWorld() ret ScatterWorld {
  var vx: List(Float) = createList(Float, cap: scatterBodyCount)
  var vy: List(Float) = createList(Float, cap: scatterBodyCount)
  var vz: List(Float) = createList(Float, cap: scatterBodyCount)
  var index: Int = 0
  loop index < scatterBodyCount {
    vx.add(value: ((index % 17) as Float) * 0.1 - 0.8)
    vy.add(value: ((index % 13) as Float) * 0.1 - 0.6)
    vz.add(value: ((index % 11) as Float) * 0.1 - 0.5)
    index = index + 1
  }
  var bodyA: List(Int) = createList(Int, cap: scatterContactCount)
  var bodyB: List(Int) = createList(Int, cap: scatterContactCount)
  var nx: List(Float) = createList(Float, cap: scatterContactCount)
  var contact: Int = 0
  loop contact < scatterContactCount {
    let a: Int = (contact * 7919) % scatterBodyCount
    var b: Int = (contact * 104729 + 13) % scatterBodyCount
    if b is a {
      b = (a + 1) % scatterBodyCount
    }
    bodyA.add(value: a)
    bodyB.add(value: b)
    nx.add(value: ((contact % 5) as Float) * 0.1)
    contact = contact + 1
  }
  ret ScatterWorld {
    vx: own vx
    vy: own vy
    vz: own vz
    invMass: filledFloats(count: scatterBodyCount, value: 1.0)
    bodyA: own bodyA
    bodyB: own bodyB
    nx: own nx
    ny: filledFloats(count: scatterContactCount, value: 1.0)
    nz: filledFloats(count: scatterContactCount, value: 0.0)
    accumulated: filledFloats(count: scatterContactCount, value: 0.0)
  }
}

# The velocity sum, times 100 and rounded: the same integer in every language
# although JavaScript and Python compute in 64-bit floats.
func scatterChecksum(world: view ScatterWorld) ret Int {
  var sum: Float = 0.0
  loop var index: Int = 0, index < scatterBodyCount, ++index {
    sum = sum + world.vx.copyAtDefault(index: index) + world.vy.copyAtDefault(index: index) + world.vz.copyAtDefault(
      index: index
    )
  }
  if sum < 0.0 {
    ret (sum * 100.0 - 0.5) as Int
  }
  ret (sum * 100.0 + 0.5) as Int
}

# copyAtDefault to read, set to write: the shortest spelling, and the slow one.
func scatterDefaultSet() {
  var world: ScatterWorld = makeScatterWorld()
  let startNs: Int = nowNs()
  loop var iteration: Int = 0, iteration < scatterIterations, ++iteration {
    loop var c: Int = 0, c < scatterContactCount, ++c {
      let a: Int = world.bodyA.copyAtDefault(index: c)
      let b: Int = world.bodyB.copyAtDefault(index: c)
      let normalX: Float = world.nx.copyAtDefault(index: c)
      let normalY: Float = world.ny.copyAtDefault(index: c)
      let normalZ: Float = world.nz.copyAtDefault(index: c)
      let invA: Float = world.invMass.copyAtDefault(index: a)
      let invB: Float = world.invMass.copyAtDefault(index: b)
      let vxA: Float = world.vx.copyAtDefault(index: a)
      let vyA: Float = world.vy.copyAtDefault(index: a)
      let vzA: Float = world.vz.copyAtDefault(index: a)
      let vxB: Float = world.vx.copyAtDefault(index: b)
      let vyB: Float = world.vy.copyAtDefault(index: b)
      let vzB: Float = world.vz.copyAtDefault(index: b)
      let previous: Float = world.accumulated.copyAtDefault(index: c)
      let normalVelocity: Float = (vxB - vxA) * normalX + (vyB - vyA) * normalY + (vzB - vzA) * normalZ
      var total: Float = previous - normalVelocity / (invA + invB)
      if total < 0.0 {
        total = 0.0
      }
      let lambda: Float = total - previous
      world.accumulated.set(index: c, value: total)
      world.vx.set(index: a, value: vxA - invA * lambda * normalX)
      world.vy.set(index: a, value: vyA - invA * lambda * normalY)
      world.vz.set(index: a, value: vzA - invA * lambda * normalZ)
      world.vx.set(index: b, value: vxB + invB * lambda * normalX)
      world.vy.set(index: b, value: vyB + invB * lambda * normalY)
      world.vz.set(index: b, value: vzB + invB * lambda * normalZ)
    }
  }
  report(name: "scatter_default_set", startNs: startNs, checksum: scatterChecksum(world: world))
}

  int64_t start = now_ns(), checksum = 0; \
  BODY \
  report(NAME, start, checksum); \
} while (0)

static void run_suite(const int64_t* values, const Particle* particles,
                      int64_t length, int64_t passes) {
  const int64_t operations = length * passes;
  /* The modulo divisor is read through a volatile so `% divisor` is a real
   * division, as it is in Rae, instead of a mask the optimiser derives from the
   * constant 65 536 (it did; it made these cases measure constant folding). */
  volatile int64_t divisor_slot = length;
  const int64_t divisor = divisor_slot;
  RUN_INT("int_sequential_unchecked", {
    for (int64_t pass = 0; pass < passes; pass++)
      for (int64_t index = 0; index < length; index++) checksum += values[index];
  });
  RUN_INT("int_sequential_checked", {
    for (int64_t pass = 0; pass < passes; pass++)
      for (int64_t index = 0; index < length; index++)
        if ((uint64_t)index < (uint64_t)length) checksum += values[index];
  });
  RUN_INT("int_collection", {
    for (int64_t pass = 0; pass < passes; pass++) {
      const int64_t* end = values + length;
      for (const int64_t* value = values; value != end; value++) checksum += *value;
    }
  });
  RUN_INT("int_constant_checked", {
    volatile int64_t constant_index = 137;
    for (int64_t iteration = 0; iteration < operations; iteration++)
      if (constant_index < length) checksum += values[constant_index];
  });
  RUN_INT("int_strided_checked", {
    int64_t index = 0;
    for (int64_t iteration = 0; iteration < operations; iteration++) {
      if ((uint64_t)index < (uint64_t)length) checksum += values[index];
      index = (index + 4) % divisor;
    }
  });
  RUN_INT("int_random_checked", {
    for (int64_t iteration = 0; iteration < operations; iteration++) {
      int64_t index = (iteration * 48271 + 17) % divisor;
      if ((uint64_t)index < (uint64_t)length) checksum += values[index];
    }

      if ((uint64_t)index < (uint64_t)length) checksum += values[index];

  });

/* Scatter update: the contact-solver-shaped read-modify-write kernel
 * (docs/physics-box3d-port-research.md), with explicit bounds checks on every
 * index so it is the same safe access the Rae versions perform. */
enum { SCATTER_BODIES = 4096, SCATTER_CONTACTS = 16384, SCATTER_ITERATIONS = 50 };

static int64_t scatter_round(float sum) {
  return sum < 0.0f ? (int64_t)(sum * 100.0f - 0.5f) : (int64_t)(sum * 100.0f + 0.5f);
}

static void run_scatter(void) {
  static float vx[SCATTER_BODIES], vy[SCATTER_BODIES], vz[SCATTER_BODIES], inv_mass[SCATTER_BODIES];
  static int64_t body_a[SCATTER_CONTACTS], body_b[SCATTER_CONTACTS];
  static float nx[SCATTER_CONTACTS], ny[SCATTER_CONTACTS], nz[SCATTER_CONTACTS], accumulated[SCATTER_CONTACTS];
  for (int64_t i = 0; i < SCATTER_BODIES; i++) {
    vx[i] = (float)(i % 17) * 0.1f - 0.8f;
    vy[i] = (float)(i % 13) * 0.1f - 0.6f;
    vz[i] = (float)(i % 11) * 0.1f - 0.5f;
    inv_mass[i] = 1.0f;
  }
  for (int64_t c = 0; c < SCATTER_CONTACTS; c++) {
    int64_t a = (c * 7919) % SCATTER_BODIES, b = (c * 104729 + 13) % SCATTER_BODIES;
    if (b == a) b = (a + 1) % SCATTER_BODIES;
    body_a[c] = a; body_b[c] = b;
    nx[c] = (float)(c % 5) * 0.1f; ny[c] = 1.0f; nz[c] = 0.0f; accumulated[c] = 0.0f;
  }
  int64_t start = now_ns();
  for (int iteration = 0; iteration < SCATTER_ITERATIONS; iteration++) {
    for (int64_t c = 0; c < SCATTER_CONTACTS; c++) {
      int64_t a = body_a[c], b = body_b[c];
      if ((uint64_t)a >= SCATTER_BODIES || (uint64_t)b >= SCATTER_BODIES) continue;
      float normal_x = nx[c], normal_y = ny[c], normal_z = nz[c];
      float inv_a = inv_mass[a], inv_b = inv_mass[b];
      float normal_velocity = (vx[b] - vx[a]) * normal_x + (vy[b] - vy[a]) * normal_y
                            + (vz[b] - vz[a]) * normal_z;
      float previous = accumulated[c];
      float total = previous - normal_velocity / (inv_a + inv_b);
      if (total < 0.0f) total = 0.0f;
      float lambda = total - previous;
      accumulated[c] = total;
      vx[a] -= inv_a * lambda * normal_x; vy[a] -= inv_a * lambda * normal_y; vz[a] -= inv_a * lambda * normal_z;
      vx[b] += inv_b * lambda * normal_x; vy[b] += inv_b * lambda * normal_y; vz[b] += inv_b * lambda * normal_z;
    }
  }
  float sum = 0.0f;
  for (int64_t i = 0; i < SCATTER_BODIES; i++) sum = sum + vx[i] + vy[i] + vz[i];
  report("scatter_checked", start, scatter_round(sum));
}

  const int64_t length = 65536, passes = 128;
  int64_t* values = malloc((size_t)length * sizeof(*values));
  Particle* particles = malloc((size_t)length * sizeof(*particles));

  free(values);
  return 0;
}

fn run_suite(values: &[i64], particles: &[Particle], passes: i64) {

    let operations = length * passes;

    // division, as it is in Rae, instead of a mask the optimiser derives from
    // the constant 65 536 (it did; it made these cases measure constant folding).
    let divisor = std::hint::black_box(length);
    bench!("int_sequential_safe_index", checksum, {
        for _pass in 0..passes { for index in 0..length { checksum += values[index as usize]; } }
    });
    bench!("int_sequential_get", checksum, {
        for _pass in 0..passes { for index in 0..length { if let Some(value) = values.get(index as usize) { checksum += *value; } } }
    });
    bench!("int_iterator", checksum, {
        for _pass in 0..passes { for value in values { checksum += *value; } }
    });

        for _pass in 0..passes { for index in 0..length { unsafe { checksum += *values.get_unchecked(index as usize); } } }
    });

        }

        }
    });
    bench!("int_mostly_valid_get", checksum, {

// Scatter update: the contact-solver-shaped read-modify-write kernel
// (docs/physics-box3d-port-research.md), with idiomatic safe `v[i]` indexing
// (bounds-checked, panics on a bad index).
const SCATTER_BODIES: usize = 4096;
const SCATTER_CONTACTS: usize = 16384;
const SCATTER_ITERATIONS: usize = 50;

fn run_scatter() {
    let mut vx: Vec<f32> = (0..SCATTER_BODIES).map(|i| (i % 17) as f32 * 0.1 - 0.8).collect();
    let mut vy: Vec<f32> = (0..SCATTER_BODIES).map(|i| (i % 13) as f32 * 0.1 - 0.6).collect();
    let mut vz: Vec<f32> = (0..SCATTER_BODIES).map(|i| (i % 11) as f32 * 0.1 - 0.5).collect();
    let inv_mass: Vec<f32> = vec![1.0; SCATTER_BODIES];
    let mut body_a: Vec<usize> = Vec::with_capacity(SCATTER_CONTACTS);
    let mut body_b: Vec<usize> = Vec::with_capacity(SCATTER_CONTACTS);
    for c in 0..SCATTER_CONTACTS {
        let a = (c * 7919) % SCATTER_BODIES;
        let mut b = (c * 104729 + 13) % SCATTER_BODIES;
        if b == a { b = (a + 1) % SCATTER_BODIES; }
        body_a.push(a);
        body_b.push(b);
    }
    let nx: Vec<f32> = (0..SCATTER_CONTACTS).map(|c| (c % 5) as f32 * 0.1).collect();
    let ny: Vec<f32> = vec![1.0; SCATTER_CONTACTS];
    let nz: Vec<f32> = vec![0.0; SCATTER_CONTACTS];
    let mut accumulated: Vec<f32> = vec![0.0; SCATTER_CONTACTS];
    let start = Instant::now();
    for _iteration in 0..SCATTER_ITERATIONS {
        for c in 0..SCATTER_CONTACTS {
            let (a, b) = (body_a[c], body_b[c]);
            let (normal_x, normal_y, normal_z) = (nx[c], ny[c], nz[c]);
            let (inv_a, inv_b) = (inv_mass[a], inv_mass[b]);
            let normal_velocity = (vx[b] - vx[a]) * normal_x + (vy[b] - vy[a]) * normal_y
                + (vz[b] - vz[a]) * normal_z;
            let previous = accumulated[c];
            let mut total = previous - normal_velocity / (inv_a + inv_b);
            if total < 0.0 { total = 0.0; }
            let lambda = total - previous;
            accumulated[c] = total;
            vx[a] -= inv_a * lambda * normal_x; vy[a] -= inv_a * lambda * normal_y; vz[a] -= inv_a * lambda * normal_z;
            vx[b] += inv_b * lambda * normal_x; vy[b] += inv_b * lambda * normal_y; vz[b] += inv_b * lambda * normal_z;
        }
    }
    let mut sum: f32 = 0.0;
    for i in 0..SCATTER_BODIES { sum = sum + vx[i] + vy[i] + vz[i]; }
    let checksum = if sum < 0.0 { (sum * 100.0 - 0.5) as i64 } else { (sum * 100.0 + 0.5) as i64 };
    report("scatter_safe_index", start, checksum);
}

Conclusions

Compiled result: Rae/C median ratios are 1.01× sequential, 1.05× random, 0.96× repeated-index, 0.98× collection-view, and 0.99× struct-view; lower is faster. Similar values are a real finding: optimized Rae optional access is usually the same branch-and-load shape as checked C.

Writes: the narrowed spellings keep Rae at 1.20× C on a read-modify-write kernel; copyAtDefault + set cost 3.90×. That gap is a compiler/library task (lower them like the narrowed forms), not a reason for unchecked access.

Language-design result: keep optional public indexing. Prefer collection loops for sequential work and element views for large structs. JavaScript and Python provide useful runtime scale, but their JIT/interpreter and heap-managed data layouts do not alter the C-backend decision. General owned opt T/RaeAny remains a separate optimization target and was not measured here.
